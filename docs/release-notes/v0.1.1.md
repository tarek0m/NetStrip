A small fix release.

## Fixed

- **Settings → "Start NetStrip with Windows" now shows what Windows will actually do.** It used to show the saved setting, which defaulted to on, so the portable build looked registered when it wasn't, and an entry left by another copy of NetStrip looked like it belonged to this one. The checkbox is now ticked only when Windows will start the copy you're running; ticking it points the start-up entry at that copy.
- **Release notes keep their headings.** Notes are now taken from `docs/release-notes/` in the repo instead of the tag message, which dropped Markdown headings.

## Downloads

- `NetStrip-0.1.1-setup-x64.exe`: per-user installer. Installs the .NET 10 Desktop Runtime if it is missing.
- `NetStrip-0.1.1-portable-x64.zip` / `NetStrip-0.1.1-portable-arm64.zip`: a single self-contained `NetStrip.exe`. On an Arm64 PC, use the arm64 zip.

These builds are not code-signed, so Windows SmartScreen may warn on first run: click **More info**, then **Run anyway**.
