NetStrip 1.0: lighter, smarter on crowded taskbars, and a closer look at each network adapter.

## Lighter

- **The installed app is about 1 MB instead of 26 MB.** Data-cap warnings now use a plain Windows notification instead of a toast library that brought in 25 MB of Windows SDK code for nothing else. The installer download shrinks accordingly.
- **The portable zips are about 10 MB smaller**, and NetStrip ships English resources only.
- **Less memory at idle:** the Fluent theme for the flyout and settings is loaded the first time you open one of them, not at startup.

## New

- **Browse your adapters in the flyout.** With more than one network adapter, use the ◀ ▶ arrows (or the Left/Right keys) to see each adapter's own speeds, graph and totals. The strip and your settings stay as they are.
- **Data cap on the strip.** With a monthly cap set, the arrows turn amber at 80% and red at 100%, and the tooltip shows how much of the cap this cycle has used.
- **Crowded taskbars.** Compact mode is now two short lines (`↑ 209 Kb` over `↓ 0.4 Mb`), much narrower than before, and it shrinks a little more to fit if it has to. When the taskbar is completely full, a new setting (Settings → When the taskbar is full) floats the strip just above the tray, or hides it, until there is room again.
- **Faster layout updates.** NetStrip re-checks the taskbar about a second after you open or close an app, instead of only at startup.

## Changed

- **Usage is recorded per adapter, in exact bytes.** "All adapters" totals and the data cap now include traffic on every adapter, even when the strip shows only the main connection.

## Downloads

- `NetStrip-1.0.0-setup-x64.exe`: per-user installer. Installs the .NET 10 Desktop Runtime if it is missing.
- `NetStrip-1.0.0-portable-x64.zip` / `NetStrip-1.0.0-portable-arm64.zip`: a single self-contained `NetStrip.exe` that needs nothing else. On an Arm64 PC, use the arm64 zip.

These builds are not code-signed, so Windows SmartScreen may warn on first run: click **More info**, then **Run anyway**.
