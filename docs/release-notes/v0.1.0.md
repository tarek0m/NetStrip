First release of NetStrip: a minimal Windows network speed monitor that shows live upload and download speeds on the taskbar, next to the system tray.

## Highlights

- Upload and download speeds on the taskbar, updated every second, in bits (default) or bytes.
- Click the strip for a flyout with a live graph, current speeds, and today's and this period's usage totals.
- Works on horizontal and side taskbars, on every monitor, at any display scaling.
- Optional monthly data cap with a warning at 80% and 100%.
- Follows light and dark mode; hides while a fullscreen app is running (on by default).
- Survives Explorer restarts, DPI changes and taskbar changes; floats as a small pill if it can't attach to the taskbar.
- Light on resources: about 35 MB working set and under 0.1% CPU when idle.

## Downloads

- `NetStrip-0.1.0-setup-x64.exe`: per-user installer. Installs the .NET 10 Desktop Runtime if it is missing.
- `NetStrip-0.1.0-portable-x64.zip` / `NetStrip-0.1.0-portable-arm64.zip`: a single self-contained `NetStrip.exe`. On an Arm64 PC, use the arm64 zip.

These builds are not code-signed, so Windows SmartScreen may warn on first run: click **More info**, then **Run anyway**.
